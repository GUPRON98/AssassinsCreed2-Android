## ✨ Fitur Utama
- 🖥️ **Full Landscape `800×480`**: Tampilan tajam dan responsif dengan pilihan **Layar Penuh (Stretch)** atau **Aspek Asli (`800×480`)**.
- 👆 **Sentuhan Penuh**: Mendukung penuh `pointerPressed`, `pointerDragged`, dan `pointerReleased` langsung di layar game.
- ⚡ **Tombol Cheat (`⚡ CHEAT` di Kiri Atas)**:
  - 🛡️ **God Mode (Kebal)** (`d.q`) — Aktifkan / nonaktifkan mode kebal bawaan game kapan saja!
- ⚙️ **Tombol Opsi (`⚙ OPSI` di Kanan Atas / Tombol Back)**:
  - 📐 Mode Layar (**Layar Penuh Stretch** / **Aspek Asli `800×480`**)
  - 🎯 Pengaturan **FPS** (`15 / 20 / 25 / 30 FPS`)
  - 📳 Toggle getar tombol (`ON / OFF`)
